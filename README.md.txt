# Project Overview
This project focuses on analyzing business sales data to identify:

- Revenue trends
- Top-selling products
- High-performing categories
- Regional sales performance
- Business growth opportunities

The analysis was performed using dashboard and visualization techniques to generate meaningful business insights and recommendations.

# Objective
The main objective of this project is to:

- Analyze sales performance data
- Identify profitable products and categories
- Understand regional business performance
- Generate actionable insights for decision-making
